לוח שמירות גורדון - הקמת שרת העריכה (חד-פעמי, כ-5 דקות, בחשבון Google של אסיף)
================================================================================
אותה שיטה כמו ניהול המשתמשים (users_admin). עד שזה נעשה, shmira.html מציג את הלוח
המוטבע (הלוח מהאקסל), והסידור נשמר רק במכשיר של העורך ("מצב ניסיון").

1. script.google.com -> "פרויקט חדש". שם: "לוח גורדון - שמירות".
2. למחוק את מה שיש בעורך ולהדביק את כל התוכן של shmira_admin/Code.gs. לשמור.
3. לבחור בפונקציה setup למעלה ולהריץ (▶). לאשר הרשאות (גיליון ומייל, בחשבון שלך בלבד).
   נוצר גיליון "לוח גורדון - שמירות" ומגיע אליך מייל עם קישור העריכה.
4. "פריסה" -> "פריסה חדשה" -> סוג: אפליקציית אינטרנט.
   להפעיל בתור: אני.  מי יכול לגשת: כל אחד.  -> פריסה.
5. להעתיק את כתובת ה-Web App (מסתיימת ב-/exec) ולשלוח ל-Claude.
   היא נכנסת ל-DUTY_API בראש shmira.html, והדף מתפרסם מחדש (באישור).
6. לפתוח את קישור העריכה מהמייל פעם אחת בכל מכשיר שממנו עורכים, ולהעביר אותו לחסן.

איך זה עובד
- כניסה: אותה רשימת משתמשים ואותה תעודת זהות כמו לוח המערכות (access_map.json +
  שינויים חיים מעמוד המשתמשים). מי שכבר מחובר ללוח המערכות באותו מכשיר - מחובר גם כאן.
- כל מי שנכנס רואה את "השמירות שלי" ואת הלוח המלא.
- "🧩 סידור הלוח" מופיע רק לחסן ולאסיף (EDITORS בדף ובשרת), ורק ממכשיר שנפתח בו
  קישור העריכה. המפתח שבקישור הוא ההגנה בפועל - לא להעביר אותו הלאה.
  שלב 1 - הגדרת הלוח: הפסקות (שעות, אחרי איזה שיעור, באילו ימים), אזורי שמירה
           (שם, כמה שומרים נדרשים), ואילו אזורים מאוישים בכל הפסקה.
  שלב 2 - שיבוץ הצוות: רשימת הצוות מגיעה ממערכת השעות (timetable.json, שנבנית מנתוני
           אפליקציית בית החינוך) + רשימת הנכנסים. לכל אחד/ת: מספר שמירות וימי נוכחות.
           הלוח מסמן משבצות חסרות ושיבוץ ביום שהמורה לא בבית הספר.
- מבנה הלוח (גרסה 2): zones [{id,name,need}], breaks [{id,name,time,after,days[6],zones[]}],
  a {"הפסקה|אזור|יום": [שמות]}. הלוח ההתחלתי (מהאקסל) מוטבע ב-DEFAULT בראש shmira.html.
- השרת שומר את הלוח המלא בגיליון (לשונית board) וכל שמירה נרשמת בלשונית history
  (מתי, מי, והלוח כולו) - כך אפשר לשחזר גרסה קודמת.
- שמות: נשמר שם איש הצוות כמו במערכת השעות ("גלית", "לי-אור"); LABEL קובע איך הוא מוצג
  ("גלית ב", "ליאור שפירא"), ALIAS מתרגם שמות מהאקסל או מהקלדה ידנית.
  שם עם קו מקווקו בשיבוץ = לא ברשימת הנכנסים, ולכן לא יראה את השמירה בכניסה.
- אם קישור העריכה דלף: בעורך הסקריפט -> הגדרות הפרויקט -> מאפייני סקריפט ->
  למחוק את EDIT_KEY ולהריץ שוב setup. קישור חדש יגיע במייל, הישן מפסיק לעבוד.

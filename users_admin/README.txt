ניהול משתמשי לוח גורדון - הקמה חד-פעמית (כ-5 דקות, בחשבון Google של אסיף)
=========================================================================
אותה שיטה כמו דף השיעורים הפרטיים (private_lessons).

1. script.google.com -> "פרויקט חדש". שם: "לוח גורדון - משתמשים".
2. למחוק את מה שיש בעורך ולהדביק את כל התוכן של users_admin/Code.gs. לשמור.
3. לבחור בפונקציה setup למעלה ולהריץ (▶). לאשר את ההרשאות שמתבקשות
   (גיליון ומייל - בחשבון שלך בלבד). נוצר גיליון "לוח גורדון - משתמשים"
   ומגיע אליך מייל עם קישור הניהול.
4. "פריסה" -> "פריסה חדשה" -> סוג: אפליקציית אינטרנט.
   להפעיל בתור: אני.  מי יכול לגשת: כל אחד.  -> פריסה.
5. להעתיק את כתובת ה-Web App (מסתיימת ב-/exec) ולשלוח לClaude.
   היא נכנסת ל-USERS_API ב-site_config.py, והלוח נבנה ומתפרסם מחדש (באישור).
6. לפתוח את הקישור מהמייל פעם אחת בכל מכשיר שממנו תנהל משתמשים,
   ולהיכנס עם תעודת הזהות שלך. תופיע לשונית "👥 משתמשים".

איך זה עובד
- הלוח מוטבע עם הרשימה הקיימת (access_map.json). הגיליון שומר רק שינויים:
  מי נוסף, מי שונה, מי הוסר. בכל טעינה הלוח מושך את השינויים - בלי בנייה מחדש.
- תעודות זהות לא נשמרות: הדפדפן הופך אותן לקוד חד-כיווני, ורק הקוד נשלח.
- לשנות אפשר רק עם שני דברים יחד: כניסה עם הת"ז של אסיף + קישור הניהול
  מהמייל במכשיר. אי אפשר להסיר את אסיף או להוריד את הרשאתו.
- אם השרת של Google לא עונה, הלוח ממשיך לעבוד עם הרשימה המוטבעת (בלי השינויים).
- כל שינוי נרשם בגיליון בלשונית log.
- אם קישור הניהול דלף: בעורך הסקריפט -> הגדרות הפרויקט -> מאפייני סקריפט ->
  למחוק את ADMIN_KEY ולהריץ שוב setup. קישור חדש יגיע במייל, הישן מפסיק לעבוד.
